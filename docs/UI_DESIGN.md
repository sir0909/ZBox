# UI v2 设计与实施状态

## 设计基准

视觉与交互基准为同目录 [`Zbox_UI_v2.html`](Zbox_UI_v2.html)。原型中的画面参数为静态演示内容，正式 Compose 界面完整绑定真实相机连接状态、回调与写入安全门禁。

## UI v2 核心布局规范

全应用统一采用近黑炭灰底色、分层卡片与尼康黄主强调色：

- 全局：加深近黑底色并拉开卡片层级，统一状态栏、品牌标记与底部导航的色彩基调。
- 监看：默认竖屏监看并保留全部拍摄控制入口；顶栏集成 Wi-Fi 配对 PIN 入口与 `InitFail [reason=1]` 内联「身份不匹配修复」指引卡。
- AI 调色：移除重复的供应商状态标签；`AI 逆向生成配方` 与 `保存` 使用等宽、同样式按钮；参考图双动作、C-1～C-9 网格及曲线/参数/写入入口保留。
- 相册：增加机身相册标题和连接/条目状态；筛选、加载、选择、对比、下载等回调未改。
- 预设库：快传码生成、复制、分享改为同排等宽同样式；供应商仍集中在预设库，预设分类与本地管理入口保留。
- 设置：日常选择、目标槽位、开关和诊断入口统一成分层卡片；默认槽位仍是对齐的 5+4 网格。
- 全屏取景：保持现有独立横屏、`ContentScale.Fit` 和左右黑边，右侧黑边控件轨道不变。

## 验收结论

- 全应用五页布局（页面眉题、取景卡片边框与脚注、黄色实心选中态、快门圆环比例、空照片预览占位、客户端身份管理卡片）均已在真机（1080×2340）与 Nikon Z 30 实测连接/取景状态下验收通过。

## UI v2.1 本地演进记录（修图工作台 & 浅色模式适配）

在 `v1.0.0` 基线上完成以下本地 UI 与交互升级（待统一发版）：

- **5-Tab 底部导航**：扩展为 `监看`、`修图`、`逆向配方`、`相册`、`预设库`；原「AI 调色 / AI 炼丹炉」统一更名为「逆向配方」。
- **可编辑滑杆组件（`EditableSliderRow`）**：所有「修图」与「逆向配方」参数滑杆支持点击右侧数字弹窗精确输入（含 `±` 切换与范围校验）及双击滑杆快速归零。
- **双主题语义色板（`ZColors` & `zcColorScheme`）**：浅色模式配置 Material 3 Mono（中对比度，`primary #4A4459`、`surface #FAF8FE`～`#E3E2E7`）并搭配克制的 `#4A4459` 实心按钮/选中态；深色模式还原最初 `v1.0.0` 尼康暗黑炭灰（`Bg #0A0B0C`、`Surface #141517`～`SurfaceHigher #26282B`）与尼康黄（`#FFE600`）主强调色。
- **覆盖层系统返回拦截（`BackHandler`）**：在 `AppRoot.kt` 为全屏覆盖层 `settingsOpen`（设置）与 `consoleOpen`（USB 调试台）注册 `BackHandler`，侧滑或系统返回键均正常退回上一界面而不直接退出 App。
- **拍照姿势翻页稳定性**：`PoseReferenceViews.kt` 固定 `290.dp` 预览图高度容器并把翻页/收藏按钮放在容器下方、标签区固定 2 行高度，切换「上一张 / 随机姿势 / 下一张」时不再导致外层页面弹回顶部。
- **首次打开更新说明弹窗**：冷启动首次检测到未读版本标识时弹出「ZBOX 更新说明」卡片弹窗，并在「设置 → 关于 → 查看本版更新说明」保留重看入口。
- **修图工作台局部蒙版与精简空状态**：空选框仅保留图标与「从手机选择照片」按钮；蒙版创建区提供 `人物 / 天空 / 主体 / 背景`（离线 ML Kit 人像分割 + 本地天空/显著主体分割）与 `径向 / 线性 / 画笔 / 亮度`；红膜覆盖层默认隐藏，仅在拖动径向/线性控制柄时临时显示或通过眼睛图标显隐。
- **监看连接卡与双模式智能构图**：修复未连接时 `ConnectBar` 使用 `ZColors.Surface` + `ZColors.Outline` 边框；监看工具栏「智能构图」默认开启零流量离线「本地智能构图」（支持 `自动三分 / 人像居中 / 极简留白`，实时在竖屏及全屏取景器叠加主体框、目标准星与机位方向提示），并支持切换至原「AI Agent 构图」。
