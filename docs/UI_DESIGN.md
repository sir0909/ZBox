# UI v2 设计与实施状态

## 设计基准

视觉与交互基准为同目录 [`Zbox_UI_v2.html`](Zbox_UI_v2.html)。原型中的画面参数为静态演示内容，正式 Compose 界面完整绑定真实相机连接状态、回调与写入安全门禁。

## UI v2 核心布局规范

全应用统一采用近黑炭灰底色、分层卡片与尼康黄主强调色：

- 全局：加深近黑底色并拉开卡片层级，统一状态栏、品牌标记与底部导航的色彩基调。
- 监看：默认竖屏监看并保留全部拍摄控制入口；顶栏集成 Wi-Fi 配对 PIN 入口与 `InitFail [reason=1]` 内联「身份不匹配修复」指引卡。
- AI 调色：移除重复的供应商状态标签；`AI 逆向生成配方` 与 `保存` 使用等宽、同样式按钮；参考图双动作、C-1～C-9 网格及曲线/参数/写入入口保留。
- 相册：增加机身相册标题和连接/条目状态；筛选、加载、选择、对比、下载等回调未改。
- 预设库：快传码生成、复制、分享改为同排等宽同样式；供应商仍集中在预设库，预设分类与本地管理入口保留。
- 设置：日常选择、目标槽位、开关和诊断入口统一成分层卡片；默认槽位仍是对齐的 5+4 网格。
- 全屏取景：保持现有独立横屏、`ContentScale.Fit` 和左右黑边，右侧黑边控件轨道不变。

## 验收结论

- 全应用五页布局（页面眉题、取景卡片边框与脚注、黄色实心选中态、快门圆环比例、空照片预览占位、客户端身份管理卡片）均已在真机（1080×2340）与 Nikon Z 30 实测连接/取景状态下验收通过。
