# PTP/IP 客户端身份与配对连接说明

## 1. 客户端名称、GUID 与相机白名单机制

- **客户端 GUID 均为本机首次随机生成（非公开固定 UID）**：
  Zbox 在某台手机首次启动时，通过 `NikonPtpDriver.ptpIpClientIdentity()` 调用 `UUID.randomUUID()` 随机生成一个 16 字节（32 位十六进制）私有 GUID，保存在应用私有偏好 `shared_prefs/ptpip_client.xml` 的 `initiator_guid` 中。正常退出、强制停止或相机开关机均不会重新生成。
- **客户端名称与自定义身份覆盖**：
  Zbox 默认发送的 PTP/IP initiator 名称为 `"Zbox"`（同时内置对旧版 `"Z-Cloud AI"` 握手名称的自动兼容回退）。若用户在设置中配置了自定义 `initiator_guid_hex`，则优先使用自定义 16 字节 GUID；清空后自动恢复本机生成的默认随机 `initiator_guid`。
- **尼康机身白名单规则**：
  Nikon Z 30 在日常 `连接到计算机`（STA 模式）下，只接受最后一次在相机 **「连接到计算机 → 配对」** 界面完成注册的那一个 GUID。未登记的 GUID 在 `InitCommand` 首包握手阶段即被机身直接拒绝，返回 `InitFail [reason=1]`（PTP/IP 标准 `Fail_Rejected_Initiator`）。

## 2. 自动配对与身份恢复机制

- **握手名称自动回退**：`openWifi` 遇到 `INIT_FAIL_REJECTED` 时，会自动在 `"Zbox"` 与 `"Z-Cloud AI"` 握手名称之间回退重试一次。
- **自动解锁重新配对**：当收到 `InitFail [reason=1]`（例如重装应用、更换新手机或相机端重置了 Wi-Fi 配置）或用户修改/重置客户端身份时，Zbox 会自动清除该 `(相机IP, GUID)` 的自动配对锁记录，并在监看页顶栏展开内联 **「身份不匹配修复」** 指引卡片。
- **可视化客户端身份管理**：「设置 → PTP/IP 客户端身份」支持查看当前客户端名称与 32 位十六进制 GUID，支持粘贴 32 位十六进制或带 `-` 的标准 36 位 UUID 保存覆盖，以及一键「恢复本机默认身份」。

## 3. 标准连接流程

- **新手机 / 首次连接相机**：在相机菜单进入 **「网络菜单 → 连接到计算机 → 配对」**，点击 Zbox 顶栏「连接」，等待约 9 秒自动完成 PIN 读取与主机注册，随后即自动转入日常连接。
- **日常使用（App 重启 / 相机开关机后）**：无需再进配对，相机开启 Wi-Fi 连接后在 Zbox 点击一次「连接」即可直连。
- **迁移已有配对身份**：若希望直接复用已登记在相机白名单中的名称与 GUID，可在「设置 → PTP/IP 客户端身份」中填入原名称与 GUID 保存后一键直连。
